# Pack workflow contract

Existing primary-key worker APIs exchange bounded, validated member reports and exact catalog evidence. Existing authenticated pages expose names, IDs, classifications and fixed status labels, not download URLs, credentials or private worker paths. Browser mutations retain POST/session-CSRF protection. DDL summary completion consumes current member evidence and does not equate a finished processing run with imported contents.

Catalog mutation rechecks current native rows and preserves existing statuses and deleted intent. Missing/ambiguous catalog response retains input. Conversion, extraction and import acknowledgement each have a distinct durable receipt boundary.
