# Acceptance checks

1. Run portable fixtures for duplicate dates, fourteen-day boundary, recovery, exclusions, mount refusal and failed backup retention.
2. Compare profile HDHR and XMLTV sets and original Plex DVR/device identities.
3. Inspect exact station mapping and current program counts; report remaining fallback channels.
4. Decode a normal selected channel and demonstrate backup selection in an isolated test channel.
5. Restore a generated application backup into isolated databases and check records/file hashes.
6. Verify recurring timers, monitor failure fixtures and current alert routing without sending a synthetic external notification.
7. Compare original credentials, physical library record IDs and recording rules/media before closing the operation.
8. Run focused validators and `make validate`, regenerate affected catalog, and record gaps in `validation.md`.
