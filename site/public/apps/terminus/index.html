TRMNL Terminus

Terminus is the self-hosted API and web backend for TRMNL e-paper devices. This stack runs the official image with PostgreSQL, Valkey (Redis-compatible), and a Sidekiq worker, matching the upstream compose.yml layout adapted for Caddy (no published host ports on the app or data stores).
