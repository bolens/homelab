Glance – self-hosted dashboard

Glance is a lightweight dashboard for RSS, weather, markets, Docker status, custom widgets, and more. Configuration is YAML (config/glance.yml). This stack runs Glance behind Caddy on the shared ingress-public network; there are no host port bindings.
