# RustFS

RustFS is a high-performance, S3-compatible object storage server written in Rust.

**GitHub:** https://github.com/rustfs/rustfs

## Usage

RustFS provides an S3-compatible API for storing and retrieving objects in your homelab.
It can serve as a self-hosted replacement for MinIO or AWS S3 for local backups and app storage.
Configure client applications with the S3 endpoint URL pointing to this service.

## Setup

1. Copy `stack.env.example` to `stack.env` and fill in required values.
2. Run `./prepare-stack.sh` to prepare local files.
3. Review the generated compose file for volume mounts and port bindings.
4. Deploy: `docker compose up -d`

## Environment variables

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| TZ | No | America/New_York | Container timezone |

## Notes

- Set strong access key and secret key credentials before exposing to a network.
- The compose file is generated by `prepare-stack.sh`; review port and volume settings before deploy.
