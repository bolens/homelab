# Dispatcharr

Dispatcharr is a self-hosted stream routing and EPG management tool for organizing IPTV channels and playlist sources.

**GitHub:** https://github.com/Dispatcharr/Dispatcharr

## Usage

Accessed via browser through a Caddy reverse proxy. Manages M3U playlists and EPG sources, then serves a unified M3U/XMLTV output consumed by Plex, Jellyfin, Emby, or ErsatzTV.

## Setup

1. Run `./prepare-stack.sh`, then review `stack.env` and `caddy_snippet.conf`.
2. Adjust `DISPATCHARR_LOG_LEVEL` if needed.
3. Deploy: `docker compose up -d`.

## Environment variables

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| DISPATCHARR_LOG_LEVEL | No | info | Application logging verbosity |

## Notes

- Caddy snippet is generated by prepare-stack.sh; configure your hostname before deploying.
- The recommended all-in-one mode runs the app, Redis, and workers in one container.
- TZ and locale come from `shared.env`; application state persists in `dispatcharr_data`.
- Pairs naturally with the ersatztv stack to build a full virtual cable headend.
- First-run setup wizard appears on initial visit to the web UI.
