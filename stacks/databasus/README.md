# Databasus

Databasus is a lightweight self-hosted database management UI for browsing and querying SQL databases via a web interface.

## Usage

Accessed via browser through a Caddy reverse proxy. Useful as a simple alternative to heavier DB admin tools for day-to-day homelab database inspection and ad-hoc queries.

## Setup

1. Copy `stack.env.example` to `stack.env` and fill in required values.
2. Set TZ to your local timezone.
3. Deploy: `docker compose up -d`

## Environment variables

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| TZ | No | America/New_York | Container timezone |

## Notes

- No default credentials are set at image level; check the first-run UI for setup prompts.
- Caddy snippet is generated by prepare-stack.sh; configure your hostname before deploying.
