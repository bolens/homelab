# ErsatzTV

ErsatzTV is a self-hosted virtual cable TV server that creates linear TV channels from your media library.

**Website:** https://ersatztv.org
**GitHub:** https://github.com/ErsatzTV/ErsatzTV

## Usage

Accessed via browser through a Caddy reverse proxy. Creates HDHR and M3U/XMLTV streams consumed by Plex, Jellyfin, Emby, or any IPTV client. Media files are mounted from NAS or local storage.

## Setup

1. Copy `stack.env.example` to `stack.env` and fill in required values.
2. Set TZ to your local timezone.
3. Mount your media library path into the container (edit compose volumes).
4. Deploy: `docker compose up -d`

## Environment variables

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| TZ | No | America/New_York | Container timezone |

## Notes

- Caddy snippet is generated by prepare-stack.sh; configure your hostname before deploying.
- Hardware transcoding (VAAPI/NVENC) requires device passthrough in the compose file.
- Pairs with the dispatcharr stack for playlist and EPG management.
