# DbGate

DbGate is an open-source database manager supporting MySQL, PostgreSQL, SQLite, MongoDB, and more via a web or desktop UI.

**Website:** https://dbgate.org
**GitHub:** https://github.com/dbgate/dbgate

## Usage

Accessed via browser through a Caddy reverse proxy. Connects to other database stacks on the same Docker network. Useful for exploring schemas, running queries, and managing multiple database engines from one interface.

## Setup

1. Copy `stack.env.example` to `stack.env` and fill in required values.
2. Set TZ to your local timezone.
3. Deploy: `docker compose up -d`

## Environment variables

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| TZ | No | America/New_York | Container timezone |

## Notes

- No authentication is enabled by default; protect the UI behind Caddy basic auth or SSO.
- Caddy snippet is generated by prepare-stack.sh; set your hostname before deploying.
- Supports connections to MySQL, PostgreSQL, SQLite, MSSQL, MongoDB, Redis, and more.
